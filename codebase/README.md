# VLearn Checkpoint — CP2 Mock

React prototype cho flow chính của lát cắt micro-quiz:

1. Học viên đọc phần tài liệu đang chọn.
2. Bấm **Kiểm tra nhanh**.
3. Trả lời ba câu hỏi mock.
4. Xem điểm, giải thích và nguồn cần xem lại.

Ở CP2, toàn bộ quiz là mock data; chưa có AI call thật. Chấm đáp án được thực hiện local để mô phỏng thiết kế tiết kiệm quota.

## Chạy local

```bash
npm install
npm run dev
```

## Kiểm tra build

```bash
npm run build
```
